What you see

TA-1 finishes at Starfactory. Structure is already 58. Fuel lines and the engine are healthy. The sheet still says not tested.

You roll it to Mega Bay. You press Check Structure. One day passes. Money does not move. The first reading is 52 to 82. The hull still says not tested. That band still holds 70. A fix from this band, with no pad test, leaves the floor at 20.

The button reads "1 day · no money". The header keeps the wind. A clear day is the day the check spends, because the pad could have used it. An empty purse can still run the check, refurb the structure, and skip the proof.

You press Check Structure again. One more day. The second reading is 50 to 60. The 70 line is out. The window names Structure short. You can start the fix now, or roll to the pad.

The cryo proof still costs 20 money and 1 pad day. It writes Structure 58. The log says it needs 70 and has 58. The rocket needs Mega Bay.

You refurb the structure. That takes 4 to 5 days. It spends no steel. Structure is 100. The factory card says the Structure floor is now 28.

TA-2 rolls from 28 to 100. Its Structure is 80. Fuel lines are 0 seconds. Thrust stays 1814 kN. The floor stays 28, because 80 clears 70.

You reload after the build, before any check. Structure is still 58. The sheet still says not tested. The same seed never rolls that number again at test time.

The roll

The real Structure number is rolled when the factory job ends. applyNewArticle at line 1598 stores it on the vehicle as stageLife. A check, a proof, and a reload do not roll it again.

The roll uses the game seed. The salt is the article count and the part. Salts 1 and 11 through 19 stay with the defect order and the sky.

function partCode(part) {
  if (part === "fitting") return 1;
  if (part === "engine") return 2;
  return 0;
}
function hiddenSalt(articleN, part) {
  return 20 + articleN * 3 + partCode(part);
}
function readSalt(articleN, part, checkN) {
  if (checkN === 1) return 80 + articleN * 3 + partCode(part);
  return 140 + articleN * 3 + partCode(part);
}
function hiddenStruct(seed, articleN, floor) {
  const lo = Math.max(TUNING.SCRAP_FLOOR, floor);
  const span = 100 - lo + 1;
  return lo + roll(seed, hiddenSalt(articleN, "stage")) % span;
}

mix32 and roll stay the functions at lines 1144 and 1150. A later change to that mix needs a new save version. This row does not change them.

The starting floor is 20. That is the scrap floor. The roll never goes under 20 and never goes over 100. 20 is initial balance.

Seed 11, article 1, salt 23, floor 20. Structure is 58. Store 58 on TA-1. Store articleN: 1 with it.

Every seeded article stores one rolled Structure. articleN is builtArticles after the increment in applyNewArticle, not the TA serial.

DEFECT_ORDERS at line 1135 is still the list. Article n takes index (n - 1) % 3 of that list. That is the same index applyNewArticle uses now.

When the index is stage, Fuel lines stay 40 seconds and thrust stays 1814 kN. When the index is fitting, Fuel lines are 0 and Structure still rolls. When the index is engine, thrust is 1400 kN and Structure still rolls.

A seeded yard ignores defectRestored.stage. defectRestored.fitting and defectRestored.engine still retire those two shorts.

A null seed does not call roll. It keeps one short, and it keeps the old cliff for all three. That short is still Structure 60, Fuel lines at 0 seconds, or thrust at 1400 kN.

The check

The first slice is Structure only. The button is Check Structure. It runs only in Mega Bay. The rocket status is in_bay. The bay still runs one job at a time.

The job lasts 1 day. It spends no money and no steel. startPartRefurb at line 4075 stays the fix. A new start, startBayCheck, writes the check job.

Use the bay job slot so Skip already lands on it. Set refurbPart to "check" and refurbLeft to 1. finishPartRefurb at line 1573 branches on "check" and does not restore Structure to 100.

startBayCheck sets the status to refurb. The bay offers Roll to the pad only while the status is in_bay, at line 3732. startPartRefurb already avoids that roll by the same status. The check does too.

The wait line and the job note read "Check Structure · 1 day left". partName at line 1315 returns Structure for any other key. The check does not use that fallback.

When the day ends, the "check" branch stores the band, clears the job, and sets the status back to in_bay. It returns before the restored log, before fundGoal, and before defectRestored. It leaves stageLife and structTested as they are. The check does not pay the refurb goal of 40.

When the day ends, derive the band from the seed, then store it. Do not roll stageLife.

function readBand(seed, articleN, part, checkN, value, width) {
  const d = roll(seed, readSalt(articleN, part, checkN)) % (width + 1);
  let lo = value - d;
  let hi = lo + width;
  if (lo < TUNING.SCRAP_FLOOR) { lo = TUNING.SCRAP_FLOOR; hi = lo + width; }
  if (hi > 100) { hi = 100; lo = hi - width; }
  if (value < lo) { lo = value; hi = Math.min(100, value + width); }
  if (value > hi) { hi = value; lo = Math.max(TUNING.SCRAP_FLOOR, value - width); }
  return { lo, hi };
}

The first width is 30. The second width is 10. Both are initial balance. Neither band is a single number. The pad still writes the exact number.

Seed 11, TA-1, first check, salt 83. The band is 52 to 82. The 70 line sits inside it. Second check, salt 143. The band is 50 to 60. The 70 line is out.

A check never damages a part. It does not set structTested. The cryo proof and a static fire that lights still do that, as they do today.

After the first check, the fix may start. After the second check, Check Structure goes off. A third bay check does not exist. The pad test still runs. Once the pad has written the number, Check Structure is off, even if the bay has not used both checks.

The cutaway still says not tested until the pad writes the exact number. The band on the Structure row holds the range. A hull fill would leak the truth.

Name Structure as short only when the high end is under 70, or when the pad has written a number under 70. A band that contains 70 does not take the miss line.

The floor

The learning curve counts faults found and fixed. A Structure fault is a stored number under 70. Finding it means a band whose high end is under 70, or a pad test that wrote the number. Fixing it means the bay restored that part to 100.

The floor rises once per article, when the refurb finishes. It rises only if the number stored at build was under 70, and a band whose high end is under 70, or a pad test, has found it.

applyNewArticle stores that fact on the vehicle as structBuiltShort. A fire cut does not set it. A lit miss takes up to 40 off Structure and leaves it at 20 at worst. It can mark the part tested. A healthy 100 can become 60. That refurb does not raise the floor. A rolled 58 becomes 20, and the rocket comes home.

The first time a band has a high end under 70, store structFound. A pad test that writes a number under 70 sets it too. A later band does not clear it. A band that still contains 70 does not set it.

The rise adds 8 to G.structFloor, then sets structFloorPaid on that vehicle. A second refurb does not add 8. A refurb from a band that still contains 70, with no pad write, leaves the floor where it is.

That 8 is initial balance. The next article rolls from the new floor to 100. The floor never passes 100. It never drops under 20.

This replaces the defectRestored.stage cliff. One fix no longer makes every later article a 100. Fuel lines and the engine keep their cliffs until a later row.

The Starfactory card says one sentence. It names the floor and the step.

From 20 to 100 there are 81 numbers, and 50 are under 70, so about 3 in 5 first articles miss. A miss costs the same 4 to 5 days as today's Structure 60. About 2 in 5 clear 70, so a floor of 20 is playable.

One fix moves the floor to 28, and 42 of 73 numbers still miss. The drop on that one fix is small. The floors then run 36, 44, 52, 60, 68, and 76.

Seven fixes reach a floor of 76. That is the first floor of 70 or more. Safe means every new article is 70 or more. Floor 68 still rolls 68 and 69.

If every miss is found and then fixed, those 7 fixes take about 31 articles. The last step, from 68 to 76, is about 17 of them, because only 2 of 33 numbers are under 70. That count is past a normal path to the hop.

On a normal path this slope does not make 0.18.0-hop safe. The new wait before the hop is a check day or two, plus a few extra structure refurbs. At 4 seconds a day, that sits inside the 10 minutes this row should add, and inside the 90 minutes of phase 0. A later sitting can move the 8.

Keep the widths. Across a uniform roll and a uniform offset, about 37 of 100 first readings straddle 70, about 43 of 100 are a known miss, and about 20 of 100 are a known pass. A true miss shows up as a miss on about 7 of 10 first readings. The 52 to 82 picture is the uncertain case, which is the right one to draw.

The floor does not reset on a new TA. It does not reset at the hop rename. A later design change, such as the stacked ship, can reset it. That reset is not this row.

What stays

  • The cryo proof still costs 20 money, takes 1 pad day, and passes at 70. It writes the exact Structure number.
  • The tanking run and the static fire stay on the pad. 6.2.0-stand still moves those pad checks inland later.
  • Fuel lines still leave at 0 seconds or 40. Thrust still leaves at 1400 kN or 1814 kN.
  • Refurb the structure stays 4 to 5 days and no steel. The button shows that span before the press. A fix restores Structure to 100.
  • Inspect the fuel lines stays 1 day and no steel.
  • Refurb the engine stays 24 steel and 2 days, or 1 day at pad level 2. These pictures use pad level 1, so that line says 2 days.
  • The bay still runs one job at a time. The one-time refurb goal pay of 40 stays.
  • The rocket name stays Test article. Serials stay TA. Steel stays 28. Build days stay 8 to 12.
  • While the rocket is on the pad, the window does not start the bay job.
  • A closed range or a short tank still scrubs. A scrub does not damage the rocket.
